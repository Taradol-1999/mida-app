# คู่มือหลังบ้าน MIDA

เข้าระบบที่ `/login` แล้วระบบจะพาไป `/admin` อัตโนมัติเมื่อเป็นผู้ดูแล

## เมนูที่มี

- **โครงการใหม่**: ใช้สร้างโครงการใหม่เท่านั้น ไม่มีรายการแก้ไขโครงการเดิมในหน้านี้
- **ข้อมูลโครงการ**: เลือกโครงการจาก Dropdown ด้านซ้ายเพื่อแก้ไขชื่อ Slug ทำเล พิกัด ประเภท ราคา สถานะ Tags รายละเอียด ภาพปก หรือลบโครงการ โดยหน้าเดียวกันจะมีข้อความ Hero สไลด์รูปภาพ/วิดีโอ และโบรชัวร์โครงการให้จัดการต่อได้ทันที
- **แบบบ้าน** และ **สิ่งอำนวยความสะดวก**: ผูกข้อมูลเข้ากับโครงการเพื่อแสดงในหน้ารายละเอียดโครงการ
- **โปรโมชั่น** และ **ข่าวสาร/กิจกรรม**: บันทึกฉบับร่างหรือกำหนดเผยแพร่ได้
- **รายชื่อผู้ลงทะเบียน**: เปลี่ยนสถานะติดตามลูกค้าและกด Export CSV ได้
- **เนื้อหาเว็บไซต์**: ปรับ Hero หน้าแรกและข้อมูลติดต่อผ่าน `content_key` ที่มีอยู่
- **จัดการสื่อโครงการ**: อัปโหลดรูปภาพ วิดีโอ และ PDF โบรชัวร์ โดยไฟล์เก็บในโฟลเดอร์ที่กำหนดด้วย `UPLOADS_DIRECTORY`
- **ผู้ใช้งานและสิทธิ์**: มีเฉพาะ Super Admin สำหรับสร้าง ปิดใช้งาน และกำหนด role ให้บัญชีอื่น

## สิทธิ์

| Role                    | สิทธิ์                                                                              |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `SUPER_ADMIN`           | ทุกเมนู รวมถึงจัดการบัญชีผู้ใช้                                                     |
| `MARKETING` (Marketing) | เห็นและจัดการเฉพาะโครงการที่ได้รับมอบหมาย ไม่สามารถจัดการผู้ใช้หรือเว็บไซต์ส่วนกลาง |

ตอนเพิ่มหรือแก้ไขบัญชี Marketing ให้เลือก **โครงการที่ดูแล** ได้หลายโครงการ และต้องเลือกอย่างน้อย 1 โครงการ ระบบโหลดรายการเดิมให้เมื่อแก้ไข Super Admin เข้าถึงทุกโครงการโดยไม่ต้องเลือก บัญชี Marketing เดิมที่ยังไม่มีการมอบหมายจะไม่เห็นข้อมูลโครงการจนกว่า Super Admin จะกำหนดให้ การถอนสิทธิ์มีผลตั้งแต่คำขอถัดไปแม้ผู้ใช้ยังล็อกอินอยู่

API หลังบ้านตรวจสิทธิ์จาก HTTP-only session cookie และโครงการของข้อมูลจริง ครอบคลุมรายการข้อมูล CSV การแก้ไข การลบ และการจัดการสื่อ ส่วน URL รูปภาพแบบบ้าน/โครงการที่ใช้แสดงหน้าบ้านยังเปิดอ่านสาธารณะได้

## ข้อควรระวัง

- อย่าลบบัญชีที่กำลังล็อกอินอยู่ และควรมี Super Admin อย่างน้อยหนึ่งบัญชีเสมอ
- อย่าลบไฟล์ในโฟลเดอร์ `UPLOADS_DIRECTORY` โดยตรง เพราะ MySQL เก็บ metadata เพื่ออ้างถึงไฟล์นั้น
- ก่อนเปิดใช้งานจริง เปลี่ยน `AUTH_SECRET`, รหัสผ่านฐานข้อมูล และรหัสผ่านบัญชีตัวอย่าง
- ราคาและข้อความตัวอย่างจาก seed data ต้องได้รับการยืนยันก่อนกดเผยแพร่จริง
