# คู่มือหลังบ้าน MIDA

เข้าระบบที่ `/login` แล้วระบบจะพาไป `/admin` อัตโนมัติเมื่อเป็นผู้ดูแล

## เมนูที่มี

- **โครงการ**: เพิ่ม แก้ไข เก็บถาวร หรือลบข้อมูลโครงการ โดยหน้าเว็บไซต์จะอ่านรายการล่าสุดจากฐานข้อมูล
- **แบบบ้าน** และ **สิ่งอำนวยความสะดวก**: ผูกข้อมูลเข้ากับโครงการเพื่อแสดงในหน้ารายละเอียดโครงการ
- **โปรโมชั่น** และ **ข่าวสาร/กิจกรรม**: บันทึกฉบับร่างหรือกำหนดเผยแพร่ได้
- **รายชื่อผู้ลงทะเบียน**: เปลี่ยนสถานะติดตามลูกค้าและกด Export CSV ได้
- **เนื้อหาเว็บไซต์**: ปรับ Hero หน้าแรกและข้อมูลติดต่อผ่าน `content_key` ที่มีอยู่
- **จัดการรูปภาพโครงการ**: อัปโหลด JPG, PNG หรือ WEBP ขนาดไม่เกิน 5 MB โดยไฟล์เก็บในเครื่องที่ `public/uploads/`
- **ผู้ใช้งานและสิทธิ์**: มีเฉพาะ Super Admin สำหรับสร้าง ปิดใช้งาน และกำหนด role ให้บัญชีอื่น

## สิทธิ์

| Role | สิทธิ์ |
| --- | --- |
| `SUPER_ADMIN` | ทุกเมนู รวมถึงจัดการบัญชีผู้ใช้ |
| `ADMIN` | จัดการข้อมูลเว็บไซต์ แต่ไม่สามารถเข้าหน้าผู้ใช้ |
| `USER` | ไม่มีสิทธิ์เข้าหลังบ้าน |

การเรียก API ทุกเส้นทาง `/api/admin/*` ตรวจสิทธิ์จาก HTTP-only session cookie อีกชั้นหนึ่ง จึงไม่อาศัยการซ่อนเมนูบนหน้าเว็บเพียงอย่างเดียว

## ข้อควรระวัง

- อย่าลบบัญชีที่กำลังล็อกอินอยู่ และควรมี Super Admin อย่างน้อยหนึ่งบัญชีเสมอ
- อย่าลบไฟล์ใน `public/uploads/` โดยตรง เพราะ MySQL เก็บ metadata เพื่ออ้างถึงไฟล์นั้น
- ก่อนเปิดใช้งานจริง เปลี่ยน `AUTH_SECRET`, รหัสผ่านฐานข้อมูล และรหัสผ่านบัญชีตัวอย่าง
- ราคาและข้อความตัวอย่างจาก seed data ต้องได้รับการยืนยันก่อนกดเผยแพร่จริง
