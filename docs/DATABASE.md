# โครงสร้างฐานข้อมูล MIDA Property

เอกสารนี้สรุปหน้าที่ของแต่ละตารางในฐานข้อมูล `mida_app` โดยชื่อในคอลัมน์แรกคือชื่อตารางจริงใน MySQL และชื่อ Model คือชื่อที่เรียกใช้ผ่าน Prisma

| ตาราง | Prisma Model | ใช้ทำอะไร |
| --- | --- | --- |
| `users` | `User` | เก็บบัญชีผู้ดูแลระบบ ชื่อ อีเมล รหัสผ่านที่เข้ารหัส บทบาท และสถานะการใช้งาน |
| `projects` | `Project` | เก็บข้อมูลหลักของโครงการ เช่น ชื่อ สถานที่ ประเภท ราคา สถานะ และคำอธิบายสองภาษา |
| `homepage_projects` | `HomepageProject` | ระบุว่าโครงการใดจะขึ้นหน้าแรก และกำหนดลำดับการแสดงผล |
| `user_projects` | `UserProject` | กำหนดโครงการที่ผู้ใช้บทบาท Marketing มีสิทธิ์ดูแลได้ |
| `house_types` | `HouseType` | เก็บแบบบ้าน รายละเอียด จำนวนห้อง พื้นที่ใช้สอย และราคาเริ่มต้นของแต่ละโครงการ |
| `facilities` | `Facility` | เก็บสิ่งอำนวยความสะดวกของแต่ละโครงการ พร้อมคำอธิบายและลำดับ |
| `promotions` | `Promotion` | เก็บโปรโมชั่นหรือข้อเสนอพิเศษ ทั้งระดับโครงการและส่วนกลาง |
| `news_items` | `NewsItem` | เก็บข่าวสารและกิจกรรมพิเศษ ทั้งระดับโครงการและส่วนกลาง |
| `leads` | `Lead` | เก็บข้อมูลผู้สนใจที่ส่งแบบฟอร์มรับข้อเสนอพิเศษ และสถานะการติดตาม |
| `activity_logs` | `ActivityLog` | เก็บบันทึกการเข้าใช้งานหน้าบ้านและหลังบ้าน เช่น เข้าชมหน้า เวลาใช้งาน การเข้าสู่ระบบ IP และ Audit Log การเพิ่ม/แก้ไข/ลบข้อมูล |
| `site_content` | `SiteContent` | เก็บข้อความหรือเนื้อหาส่วนกลางของเว็บไซต์ MIDA ที่ไม่ผูกกับโครงการ |
| `media_assets` | `MediaAsset` | เก็บเมทาดาทาของไฟล์ที่อัปโหลด เช่น รูปภาพ วิดีโอ เอกสาร ประเภทไฟล์ และลำดับแสดงผล |
| `project_settings` | `ProjectSetting` | เก็บการตั้งค่าเฉพาะโครงการ เช่น Hero ข้อมูลติดต่อ แผนที่ สถานที่ใกล้เคียง และบริการหลังการขาย |
| `page_views` | `PageView` | ตารางสถิติเข้าชมเดิม เก็บไว้เพื่ออ้างอิงข้อมูลเก่าเท่านั้น ระบบปัจจุบันไม่ได้ใช้งานแล้ว |

## ข้อควรรู้

- ระบบเข้าถึงฐานข้อมูลผ่าน Prisma schema และ Prisma models เท่านั้น
- ตาราง `page_views` ถูกคงไว้เพื่อไม่ให้ข้อมูลเดิมสูญหาย แต่ Prisma ทำเครื่องหมาย `@@ignore` แล้ว
- สถิติใหม่ใช้ตาราง `activity_logs` แทน เพื่อรองรับทั้งหน้าบ้านและหลังบ้าน
